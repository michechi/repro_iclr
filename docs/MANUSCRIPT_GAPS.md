# Manuscript evidence and build gaps

The anonymous [manuscript source](../paper/manuscript_source.tex) mirrors the current working draft with comment lines removed. It is **not a validated final paper**. This file records discrepancies found by checking its claims, tables, and dependencies against the packaged aggregate evidence. It does not replace unavailable measurements with plausible values. [RESULTS_INVENTORY.md](RESULTS_INVENTORY.md) identifies the measured files and their protocols. "Snapshot line" numbers below refer to the manuscript source in this release.

## Figure and build dependencies

The source references `auc_main_iclr.png` and `auc_appendix_iclr.png`. Neither image is available, and no verified all-model/all-task fraction dataset is bundled. The KIP large-model fraction CSV covers only its four arms and four completed fractions and is rendered as a KIP-4-only figure at `paper/figures/kip_data_efficiency/data_efficiency.png`. It is insufficient to recreate the requested OC/GPC/KIP panels. No substitute curve should be manufactured from manuscript endpoints.

The three attention figures have available aggregate plotting inputs:

- [OC layer profiles](../paper/figures/attention_oc_profiles_20260925.csv): 264 aggregate rows for five audits.
- [KIP selected-checkpoint profiles](../paper/figures/attention_kip_m4_profiles_20260925.csv): 448 rows for four successful KIP-4 checkpoints, selected from 22 audits.
- [CKD layer profiles](../paper/figures/attention_ckd_profiles_20260925.csv): 144 rows for four models and two conditions, each summarizing 1,000 patients.

Each has companion JSON metadata, and `scripts/reproduce_figures.py` regenerates the three figures from these CSVs; `scripts/check_datasets.py` validates the bundled datasets. Both scripts run from the release, the root test suite passes (391 passed, 3 environment-dependent skips) and the nested `repro` suite passes (182 passed). These checks establish that the aggregate figures and datasets are consistent; they do not establish that the missing measurements exist or that the manuscript compiles. The raw-audit plotting scripts may reference original attention summaries or clinical per-patient files that are deliberately absent; use the aggregate figure-regeneration route. An absent generated PNG is different from an absent measured input.

The mechanism-identification plots under `results/mechanism_id_reference/plots/` are rendered outputs of the unarchived ladder, held-out-rule and parity-decomposition CSVs; they accompany `report.md` and do not substitute for those CSVs. The three aggregate CSVs of that audit are also duplicated at their original path `repro/src/analysis/mechanism_id/results/`, so `scripts/audit_kip_feature_table.py` and the provenance paths that name that location now resolve; the copies are not additional experiments.

The main source requests `iclr2027_conference.sty` and `iclr2027_conference.bst`; the release does not contain those files. Building a full conference-formatted manuscript also requires those external style files and normal LaTeX dependencies. A standalone appendix build or successful aggregate figure generation does not establish that the full manuscript compiles.

The bundled bibliography does not define these seven citation keys used by the manuscript:

`kgram`, `kip1`, `kip2`, `kip3`, `kip4`, `qlora`, `qwen38`.

The bibliography also cannot establish the empirical provenance of a row: missing citations and missing measurements are separate issues. No bibliography entries were invented to make the build appear complete.

Sanitized scheduler templates now live under `repro/scripts/slurm/` (including the `sensitivity_*` launchers and `hpc_templates/experiment_F_*`), which resolves the launcher references in `repro/REPRODUCING.md`. They document how runs were submitted; they are not evidence that any run completed. `repro/REPRODUCING.md` still links to `results_reference/README.md`, but no `repro/results_reference` directory is in the release. The search for missing learning-curve data covered the local result folders, historical logs and simulation-data locations; the retained full-data endpoint logs and aggregate feature controls do not supply the missing OC/GPC fraction grid.

## Release boundary

Measured aggregates, theoretical reference values, historical table snapshots, redacted aggregate reports, pending summaries, and draft manuscript prose are distinct evidence classes. Presence in the same archive does not make them interchangeable. In particular, no GPC attention audit, completed Llama-70B fit on any task, completed Qwen3-4B-Think fit, raw-token OC/GPC XGBoost fit, fine-tuned neural GPC fit, stochastic sensitivity fit, or completed clinical AKI/MACE/stroke/radiology result is claimed by this artifact. Clinical raw data and patient-level derived artifacts remain excluded, as do raw logs, the cancelled 70B plan, the partial Llama-8B KIP-6 attempt and the private analysis note behind the λ-agnostic cells.

These gaps are retained visibly so that readers can reproduce the available figures and inspect the measured results without mistaking absent, transcribed or simulated evidence for completed experiments.
